# Joshua Ly — Ideas in Motion

Joshua Ly’s personal freelance portfolio: interactive demos, selected work, and live geometric motion graphics.

## Open the site

Open `index.html` in a modern browser. The portfolio is a self-contained static page with embedded fonts and demo files; no build step or backend is required.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**. Save to publish. The `.nojekyll` file preserves the static site as supplied.

## What is included

- Animated geometric studies with motion controls and reduced-motion support.
- Featured projects, an interactive project gallery, and case studies.
- Interactive demo walkthroughs using illustrative sample data.
- Email inquiries addressed to Joshua’s personal contact address.

Optional Mermaid and BPMN diagrams load their viewers from a CDN when requested. The core portfolio and process descriptions work without those viewers. Inquiry forms prepare an email draft for the visitor to review and send; this site does not submit it to a server.

This repository is Joshua’s personal portfolio. It is maintained separately from Jeff Electric’s repositories and company website.
